Chapitre 1 — Les bases de Python

▼

Exercice 1.1

Écrire un programme qui affiche "Bonjour le monde".

print("Bonjour le monde")
La fonction print() permet d'afficher du texte à l'écran.

Exercice 1.2

Demander le nom de l'utilisateur et l'afficher.

nom = input("Quel est ton nom ? ")
print("Bonjour", nom)
input() permet de récupérer ce que l'utilisateur tape au clavier.

Chapitre 2 — Les variables et types

▼

Exercice 2.1

Créer deux variables et afficher leur somme.

a = 15
b = 27
print(a + b)
On peut faire des calculs directement avec les variables.

Exercice 2.2

Convertir une chaîne en nombre entier.

texte = "42"
nombre = int(texte)
print(nombre + 8)
int() convertit une chaîne de caractères en nombre entier.

Chapitre 3 — Les conditions

▼

Exercice 3.1

Vérifier si un nombre est positif, négatif ou nul.

n = int(input("Entrez un nombre : "))

if n > 0:
    print("Positif")
elif n < 0:
    print("Négatif")
else:
    print("Nul")
On utilise if / elif / else pour tester plusieurs conditions.
